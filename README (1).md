# 金价每日速报 · 全自动抓取版

部署到你的 Streamlit 应用后，**打开页面即自动抓取数据并填满整份《金价每日速报》PDF**，不再需要手填 data_config.py（本版本已不需要该文件，可删除）。

## 一、它自动做了什么
打开页面 → 自动抓取 → 自动计算 → 自动填写 → 一键下载 PDF / 趋势长图 / 采购小结。

自动抓取的**真实实时数据**（均为海外可直连、免密钥接口，云端稳定）：
- 国际现货金价 XAU / 白银 XAG：api.gold-api.com
- 美元兑人民币：open.er-api.com（兜底 frankfurter.app）
- 逐日历史金价序列（用于涨跌/振幅/52周高/均线/支撑阻力）：优先 Yahoo GC=F，失败自动回落 NBP 波兰央行官方金价（折美元/盎司）
- 逐日美元兑人民币历史：frankfurter.app

由真实数据**自动计算并填入**报告的：伦敦金涨跌与振幅、COMEX 主力（升水估算）与换算元/克、SGE 日/夜盘折算参考价、竞品零售与价差、技术面支撑/阻力/均线、短期预判区间、风险等级。

## 二、为什么这样设计（避免再次“取不到数据”）
前几轮反复失败的根因：Streamlit Cloud 在海外，上金所 / 金投网 / 汇通 / akshare 等国内接口对海外服务器直接拒绝。因此本版只依赖海外可直连的国际数据源做实时抓取；凡境内权威值（交易所官方结算/延时、各品牌实时牌价、宏观数据具体值、机构最新研报）**无法从海外抓取**，一律按真实数据“折算 / 估算”并在页面与报告中**明确标注口径（估算 / 待核实）**，绝不冒充官方数值。

口径提醒：页面里的人民币价是“国际金价 × 实时汇率 ÷ 31.1035”折算的交易所大盘参考价，低于周大福等金店零售价属正常（后者含工费与品牌溢价）。

## 三、上传与部署（最短路径）
1. 打开 GitHub 仓库 gold-model 首页 → Add file → Upload files，把本目录 3 个文件（streamlit_app.py、requirements.txt、README.md）一起拖入；同名提示覆盖时确认覆盖 → Commit changes。
   - 若仓库里还留着旧的 data_config.py，可以删掉（本版不再使用）。
2. 打开应用页 → 右上角 Manage app → Clear cache，再 Reboot，状态变 Running 后刷新页面。
3. 页面打开即显示实时金价、汇率、风险等级，点 PDF 报告 / 趋势长图 / 采购操作小结 标签页即可下载。

## 四、报告数据明细（可选核对）
页面“报告数据明细”标签会展示所有自动算出的表格，便于核对各板块填充结果。

## 五、如果还是不显示
1. Manage app → Logs 看具体报错（多数是某个接口临时超时，刷新或 Clear cache 即恢复）。
2. 若历史源显示“无”，是 Yahoo 与 NBP 同时超时，刷新即可；实时金价仍会显示。
3. 若需要境内官方延时行情 / 各品牌实时牌价 / 机构最新研报的精确数值，请在 sge.com.cn、金十数据、汇通财经等终端核对（这些无法从海外节点直连）。
