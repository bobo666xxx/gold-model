# =============================================================================
# requirements.txt —— 用于 Streamlit 社区云（Community Cloud）自建网址运行
# 项目：金价每日速报生成器（gold-model）
#
# 【放置位置】GitHub 仓库根目录，与 streamlit_app.py / gold_price_report.py 同级。
# 【命名要求】文件名必须一字不差是 requirements.txt（全小写、单数、.txt），
#             写成 requirement.txt / requirements.TXT / Requirements.txt 都不会被读取，
#             这是"部署后白屏 + ModuleNotFoundError"最常见的原因。
#
# 【Streamlit 社区云部署三步】
#   1. 仓库根目录放三个文件：streamlit_app.py（网页入口）、gold_price_report.py（核心模块）、
#      requirements.txt（本文件）。入口脚本名建议用 streamlit_app.py 或 app.py，
#      部署时可在 "Settings → App entry point / 入口文件" 里手动指定。
#   2. 打开 https://share.streamlit.io/deploy → 登录 GitHub → New app →
#      选 Repository / Branch / Main file path(选 streamlit_app.py) → Deploy。
#   3. 构建日志里若出现 "Installing requirements" 说明本文件已被正确识别；
#      没有出现这一行 = 文件名或位置不对。
#
# 【注意事项】
#   - 不要写 streamlit 以外的安装器指令（如 --index-url、-e .、pip install xxx），
#     社区云用受限的 pip 环境解析，写了会直接构建失败。
#   - 不要写本地绝对路径、不要写 git+https 的大依赖，冷启动会超时。
#   - 社区云跑在免费容器里，实例闲置后会休眠，再次访问冷启动约 10~30 秒，属正常现象。
#   - 依赖装不上时，先删掉带版本区间的约束（把 >= 那一行改成只写包名）再重新部署。
# =============================================================================
